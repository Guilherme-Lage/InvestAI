Bem-vindo ao InvestAI

Este é o frontend do InvestAI, que consome a API do backend em Flask. Use o menu acima para gerenciar Usuários, Movimentações, Investimentos e Metas. Cada tela permite cadastrar, listar, editar e excluir os dados chamando as rotas CRUD da API.

Antes de usar, certifique-se de que o backend está rodando em http://127.0.0.1:5000.
