# InvestAI

Aplicativo de gestão e educação financeira pessoal com IA: guia o usuário desde o
controle básico de gastos até recomendações de investimento por perfil de risco,
liberadas somente depois que ele forma uma reserva de emergência equivalente a 3
meses de despesas. Projeto acadêmico com os 20 requisitos funcionais (RF01–RF20) do
relatório de elicitação de requisitos implementados.

Backend em Flask (API REST com autenticação JWT) e app mobile em Flutter.

Documentação completa — arquitetura, models, rotas da API, checklist de RF01–RF20 e
como rodar o projeto — está em [`investai/README.md`](investai/README.md).
